# Vite & Gourmand

## Présentation

Vite & Gourmand est une application web permettant de consulter les menus,
passer des commandes et gérer les fonctionnalités administratives du site.

## Technologies utilisées

- HTML
- CSS
- JavaScript
- PHP
- SQLite

## Installation en local

1. Cloner le dépôt :
   git clone git@github.com:nasfiachra-sketch/Vite-et-Gourmand.git

2. Placer le projet dans le dossier du serveur local.

3. Vérifier la configuration de la base de données dans `config.php`.

4. Démarrer le serveur local.

5. Ouvrir l'application depuis le navigateur.

## Base de données

Les fichiers SQL nécessaires à la création et à l'alimentation de la base
de données sont disponibles dans le dossier `sql`.

## Utilisation

L'application permet notamment :
- de créer un compte ;
- de se connecter ;
- de consulter les menus ;
- de passer une commande ;
- de gérer son compte ;
- de laisser un avis ;
- d'administrer les menus et les plats selon les droits de l'utilisateur.

## Sécurité

- Les mots de passe sont protégés.
- Les accès aux fonctionnalités d'administration sont contrôlés.
- Les données utilisateur sont validées côté serveur.
- Les requêtes vers la base de données sont sécurisées.
