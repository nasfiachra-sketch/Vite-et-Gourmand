# Vite & Gourmand

Application web de gestion et de commande de menus.

## Installation en local

1. Cloner le dépôt :
   git clone git@github.com:nasfiachra-sketch/Vite-et-Gourmand.git

2. Placer le projet dans le serveur local (XAMPP/MAMP).

3. Importer la base de données :
   sql/database.sql

4. Configurer la connexion à la base de données dans `config.php`.

5. Ouvrir l'application depuis le serveur local.

## Technologies

- HTML / CSS
- JavaScript
- PHP
- SQLite / SQL
